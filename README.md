# CodeAlpha_StockTradingPlatform

## Overview
Stock Trading Platform is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.It simulates a basic stock trading environment where users can view stocks, buy and sell shares, track portfolio performance, and manage transactions.

## Features
- View available stocks
- Buy stocks
- Sell stocks
- View owned stocks
- Track portfolio performance
- View profit and loss
- View transaction history
- Save portfolio data
- Menu-driven console interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- File Handling
- Collections Framework

## Project Structure
CodeAlpha_StockTradingPlatform/
│── StockTradingPlatform.java  
│── Stock.java  
│── Portfolio.java  
│── Market.java  

## File Description

### StockTradingPlatform.java
Main file that controls program execution using switch-case menu options.

### Stock.java
Defines stock properties such as stock name and price.

### Portfolio.java
Handles buying, selling, portfolio tracking, transaction records, and profit/loss calculations.

### Market.java
Displays available stocks and market-related information.

## Functionalities

### View Stocks
Displays all available stocks with prices.

### Buy Stock
Allows users to purchase stocks.

### Sell Stock
Allows users to sell purchased stocks.

### View My Stocks
Shows all stocks owned by the user.

### View Portfolio
Displays complete portfolio summary.

### View Profit/Loss
Calculates portfolio performance.

### View Transactions
Displays transaction history.

### Save Portfolio
Stores portfolio data for future use.

4. Select menu options to interact
